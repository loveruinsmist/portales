# portales


Convierte coordenadas entre el Overworld y el Nether

- 1 bloque en el Nether = 8 bloques en el Overworld

## Funciones

- Overworld → Nether
- Nether → Overworld
- Soporte para coordenadas negativas
- Uso simple desde terminal

## Requisitos

- Python 3

## Cómo usar

Clona el repositorio:

bash
git clone https://github.com/loveruinsmist/portales.git

Entra en la carpeta:
cd portales

Ejecuta el archivo:
python portales.py
